# Go Piscine — Gritlab


## About the Piscine

The Go Piscine at **Gritlab** is an intensive, hands-on programming experience designed to develop fundamental programming skills through practical exercises, individual challenges, and projects.

Rather than focusing only on theoretical concepts, the Piscine emphasizes learning by doing. Each exercise introduces or reinforces programming concepts, requiring students to understand problems, develop solutions, debug their code, and apply what they have learned to increasingly complex challenges.

Working through the Piscine provided an opportunity to develop a stronger understanding of programming with Go (Golang), improve problem-solving skills, and become more comfortable working independently with unfamiliar problems.

**I successfully completed the Go Piscine at Gritlab.**

## Quests and Exercises

The Piscine was organized around progressive exercises and challenges. Each stage contributed to developing a stronger foundation in Go and programming logic.

The `piscine-go/` directory contains my Go exercises and implementations completed throughout the program.

The exercises cover different programming concepts, including fundamental operations, strings, numeric conversions, algorithms, recursion, pointers, linked lists, binary trees, and other programming challenges.

Rather than treating each exercise as an isolated task, the goal was to understand the underlying concepts and apply them to different problems.

## Projects

In addition to individual exercises, I completed projects that brought together different programming concepts and required more structured problem-solving.

### 1. Piscine Go

**Directory:** `piscine-go/`

A collection of Go exercises completed during the Piscine.

This part of the repository demonstrates my progression through Go fundamentals and more advanced programming concepts, including:

- Functions and control structures.
- String and number manipulation.
- Algorithms and recursion.
- Data structures.
- Linked lists and binary trees.
- Problem-solving and debugging.

### 2. Quad

**Directory:** `quad/`

A project focused on generating geometric patterns using Go.

The program works with dimensions to produce rectangular patterns using specific character combinations.

This project helped develop my understanding of:

- Nested loops.
- Functions and modular code.
- Coordinate-based logic.
- Pattern generation.
- Handling different dimensions and edge cases.

### 3. Quad Checker

**Directory:** `quadchecker-1/`

A project designed to identify and validate generated geometric patterns.

Given a pattern as input, the program analyzes its dimensions and structure to determine which predefined Quad pattern or patterns match the input.

Concepts explored:

- Input processing.
- String manipulation.
- Pattern recognition.
- Conditional logic.
- Validation and edge-case handling.

### 4. Sudoku

**Directory:** `sudoku/`

A Sudoku-solving project involving logical validation and algorithmic problem-solving.

The objective is to work with a Sudoku grid, validate its constraints, and find a valid solution.

This project involves:

- Two-dimensional data structures.
- Backtracking and recursion.
- Constraint checking.
- Algorithmic problem-solving.
- Managing state during recursive execution.
